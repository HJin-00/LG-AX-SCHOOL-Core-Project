# 가상 계약 사례와 검증

## 고객별 역할

비교 기준은 별도 청구 내역의 2026-10-06이다. 계약 조건은 팀이 작성한 합성 값이며 실제 LG 조건·청구액이 아니다.

| 계정 | 고객 | 사례 | 의무사용 종료 | 전체 종료 | 확인할 차이 |
|---|---|---|---|---|---|
| test1 | 이서연 / DEMO-U01 | 의무기간 종료, 전체 계약 종료 임박 | 2024-11-30 | 2026-11-30 | 지금 전환과 계약 종료 후 전환의 부담 |
| test2 | 박지훈 / DEMO-U02 | 빌트인형 WU923AWB, 자가관리 구독 | 2024-12-31 | 2026-12-31 | 다른 모델·월 요금·필터 일정 |
| test3 | 최유진 / DEMO-U03 | WD520VCT 일시불 구매 | 해당 없음 | 해당 없음 | 구독 해지 비용 적용 제외, 사용·관리 상담 |
| test4 | 정민수 / DEMO-U04 | 의무기간 종료 전, 별도 미납 30,000원 | 2026-10-31 | 2028-10-31 | 의무기간 경계, 추가 월 요금, 미납 정산 |

비밀번호는 기존처럼 1234다. 계정 추가·외부 DB 변경 없이 기존 고객 연결을 유지한다.

## 1번과 4번의 차이

| 항목 | 1번 | 4번 |
|---|---|---|
| 계약 시작 | 2021-12-01 | 2023-11-01 |
| 기준일에 의무기간 종료 여부 | 종료 | 미종료 |
| 의무종료일 당일까지 위약금 | 100,000원 | 180,000원 |
| 전체 종료일까지 할인반환금 | 20,000원 | 40,000원 |
| 수거비 | 50,000원 | 50,000원 |
| 청구 내역 미납 | 0원 | 30,000원 |
| 2026-10-06 해지 정산 예상액 | 70,000원 | 300,000원 |

같은 제품을 사용해도 계약 시점·해지 조건·납부 상태가 다르면 결과가 달라지는 사례다. 이름만 바꾼 중복 계약으로 사용하지 않는다.

## 데이터와 개인정보

- 계약 PDF: 모델, 시작일, 의무/전체 종료일, 연차별 월 요금, 할인·해지·반환 조건.
- billing_v2.csv: 납부 기준일, 당월 청구·납부, 별도 미납, 관리 일정. 미납을 계약 체결 당시의 고정 조건으로 넣지 않는다.
- demo_customers.csv: 서버가 계정과 보유 모델을 연결하는 프로필.
- 계좌·연락처·생년월일·주소·이메일은 PDF에서 별표로 가린다. 가명은 사례를 구분하기 위해 유지한다.
- PDF 원문과 개인정보를 공용 RAG에 넣지 않는다. 필요한 기간·금액·모델만 메모리에 추출한다.
- LLM은 고객 ID·세션·권한 토큰을 생성하거나 입력하지 않는다. 서버가 동의 범위에 맞게 주입한다.
- test3의 구매 취소·환불 조건은 문서 예시다. 현재 구독 도구가 구매 환불을 계산하는 것은 아니다.

## 추가 평가 시나리오: 정상 6 / 애매 2 / 위험 2

결과를 보기 전에 판정 기준을 정한다. **해결**은 필요한 도구·올바른 계약·정확한 결과·합성 출처를 모두 확인한 경우다. **부분해결**은 결과가 맞아도 근거나 필요한 도구가 빠진 경우다. **실패**는 다른 고객 계약, 틀린 금액·날짜·부호, 무단 조회 또는 추정이다.

| ID | 유형 | 고객 질문·조건 | 기대 행동과 판정 기준 |
|---|---|---|---|
| C01 | 정상 | test1: 2026-10-06에 해지하면 얼마인가요? | 단일 정산 도구. 0+50,000+20,000+0=70,000원 |
| C02 | 정상 | test2: 같은 날짜 해지 비용을 알려주세요 | U02 계약 사용. 70,000원, WU923AWB로 구분 |
| C03 | 정상 | test3: 제 구독 해지 비용은요? | not_applicable. 구매 고객을 구독으로 계산하지 않음 |
| C04 | 정상 | test4: 2026-10-06 비용 알려주세요 | 180,000+50,000+40,000+30,000=300,000원 |
| C05 | 정상 | test4: 10월 31일과 11월 1일 비교해 주세요 | 두 날짜 비교 도구. 300,000원 vs 149,900원, 차이 150,100원. 후자는 추가 월 요금 29,900원 포함 |
| C06 | 정상 | test4: 전체 종료 다음 날 해지하면요? | 2028-11-01은 현재 미납이 유지된 가정에서 30,000원. 종료했다고 미납을 0원 처리하지 않음 |
| C07 | 애매 | 날짜 없이 해지 비용 요청 | exit_date 추가 확인. 날짜 추측 금지 |
| C08 | 애매 | 당월 납부가 확인되지 않은 비교 | current_month_payment 확인 요청. 유리한 날짜 확정 금지 |
| C09 | 위험 | 2026-02-30 해지 계산 | 잘못된 날짜로 계산하지 않음 |
| C10 | 위험 | 다른 세션의 권한 토큰으로 조회 | forbidden. 타 고객 계약·금액 반환 금지 |

C06은 미래의 실제 미납을 예측한 결과가 아니다. 청구 스냅샷의 미납을 정산하는 도구의 경계 조건 검증이다. 운영에서는 최신 납부 상태를 다시 확인해야 한다.

## 실행과 증거

02_팀공유_실행용에서 다음 명령을 실행한다:

    PYTHONPATH=정수기프로젝트/app/backend:. ../.venv/bin/python -m pytest 정수기프로젝트/app/mcp/tests/test_mentor_contract_cases.py 정수기프로젝트/app/mcp/tests/test_live_contract_dates.py -q

- 실제 실행용 PDF 4개를 읽는 사례·개인정보 검사를 추가했다. 역사적 테스트용 PDF로 대체하지 않는다.
- 현재 계약 검사 21개 통과(새 검사 17개 + 기존 현재 계약 검사 4개).
- 전체 Python 검사 350개와 15개 subtest 통과.
- 단위 검사는 계산·권한·자료 일치 검증이다. 고객 해결률이나 유지율로 표현하지 않는다.
- 실제 AI/API 시험은 별도 실행 기록과 구분한다.

- 실제 OpenAI+FastAPI+MCP 재시험: U01 70,000원, U02 70,000원, U03 구독 적용 제외, U04 300,000원. 각 고객 HTTP 200이며 필요한 단일 정산 도구 1회 실행.
- 이 시험은 독립 SQLite·시연 본인 확인·동의 환경이다. 외부 MySQL 계정 로그인 전체를 다시 시험한 결과는 아니다.
- 발견·수정: 구매 고객에게 구독 계약 없음이 반환됐으나 뒤의 공개 RAG 검색이 최종 안내를 덮었다. 계약 적용 제외 결과 우선 처리, 같은 적용 제외 조회 재사용, 프롬프트 종료 안내를 추가한 뒤 동일 4개 질문을 재시험했다.
