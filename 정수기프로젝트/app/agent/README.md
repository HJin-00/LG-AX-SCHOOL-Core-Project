# 단일 계약 상담 Agent

system_message.txt는 업무 실행·응답 지침, consultation_plan.py의 PLAN_INSTRUCTIONS는 같은 LLM의 사전 목적 판단 지침이다. 두 지침은 역할을 나누고 상담 흐름을 동일하게 유지한다. langchain_agent.py의 TOOLS 11개와 MCP 등록부·client_adapter 허용 집합이 일치한다. 고객 질문으로 필요한 조회·계산·준비서를 LLM이 선택한다. 유지·새 모델 재구독 비교는 유지하고 사용방법·오류·관리 일정 도구는 공식 채널 안내로 대체한다.

공식 AI Chat URL은 https://www.lge.co.kr/ai-commerce/aiAssistant 이며 실제 공식 버튼을 눌러 확인했다. 대화·계약·권한값을 외부로 전달하지 않는다.

## 상담 목적과 도구 선택

같은 LLM이 먼저 현재 질문의 목적·교체 이유·구체 선택을 구조화하고, 입력에 실제 있는 문구로 근거를 확인합니다. 이후 같은 단일 Agent가 MCP 명세를 보고 필요한 도구를 선택합니다. 두 번째 Agent나 키워드별 강제 도구 호출은 없습니다. 잘못 인용한 근거와 모순된 목적은 구조화 응답 검증에서 재판단합니다.

교체 이유가 없다면 이유부터 묻고, 현재 계약 월요금 질문에는 불필요한 정산 실행을 차단합니다. 서버가 확인한 비용 동의가 없는 월요금 질문은 동의를 먼저 안내합니다. 선택한 새 상품의 비용·카드 혜택 비교는 실제 비교 도구 결과가 있어야 완료로 답할 수 있습니다.

카드 기본값은 미사용/실적·자격 미확인입니다. 고객이 고른 카드, 인정실적, 자격, 등록 검토일만 도구에 전달하며 기본 할인과 행사 추가 할인 기간을 분리합니다. 최대 혜택은 별도 참고 시나리오이며 실제 월 청구액·미확인 개인 견적으로 확정하지 않습니다.

## 해지·교체 경계와 코드 책임

- consultation_plan.py: 현재 의도(해지 결정/고민/불편, 교체)를 판단하고 목적 간 모순을 검증합니다. 비용 확인 요청은 과거 해지 고민보다 우선합니다.
- system_message.txt: 해지 시 이유 강요 없이 비용 확인, 교체 시 이유별 도움, 공식 지원 연결과 분쟁 경계를 안내합니다.
- langchain_agent.py: LLM 도구 선택, 권한·입력·실제 완료 검증을 담당합니다. 폐기된 사용오류/설치/구매 도구의 후처리 분기는 제거했습니다.
- next_actions.py: 답변 후 화면에 제공할 허용 행동을 한 곳에서 정의합니다. 공식 연결 버튼을 누른 뒤에 LLM이 공개 채널 도구를 선택합니다.
- response_topics.py: 실행 결과의 화면 주제만 정하며 업무 도구를 호출하지 않습니다.

해지를 결정하면 오늘 기준 정산을 확인하고, 고민 중이면 이유 답변을 강제하지 않고 비용 확인·문제 해결 선택을 제공합니다. 실제 해지 접수·면제 확정은 지원하지 않습니다.
