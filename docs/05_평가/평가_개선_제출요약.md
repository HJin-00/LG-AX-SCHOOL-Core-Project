## 실패 → 개선

- 검색 실패: 관리 서비스 미제공·청구와 AS 지연이 다른 사례로 검색됨 → 공개 후보의 질문·상황을 검토하고 중복 후보를 줄임 → 같은 검색20개 2회와 변형6개 통과.
- Tool 오류: 두 날짜 정산만 반복해 사이 이용요금 누락 → 전용 날짜 비교 결과를 완료 조건으로 확인 → 같은 상담 시나리오 통과.
- 대화 맥락 문제: 잘못된 날짜 입력이 앞선 후보 목록에 가려짐 → 마지막 계산의 정보 요청 우선 → 같은 상담 시나리오 통과.
- 프롬프트 문제: 공개 포인트 조건 요청을 개인 동의로 전환 → 공개 근거 검색으로 처리 → 같은 상담 시나리오 통과.
- 대화 맥락 문제: 해지 고민 뒤 비용을 선택해도 선택지를 반복 → 현재 비용 확인 목적을 우선 → 추가10개 9/10에서 10/10.

## 판정

해결: 필요한 실행·근거·조건·권한을 충족하거나 적절한 질문·거절 수행. 부분해결: 핵심 답변은 맞지만 일부 누락. 실패: 오답·추측·허위 완료·권한 위반·필수 행동 누락.

[전체 시나리오](평가_시나리오_최신.md), [검색·전체 상담 기록](RAG_하이브리드_검색/개선_검증.md), [해지 추가 검증](해지상담_추가검증/개선_검증.md)에서 각 실행을 구분한다. 기존 기록은 해당 시점의 검증이며 현재 결과와 합산하지 않는다.

가격은 확인일 조건이며 미래 견적·개인 할인·분쟁 면제를 확정하지 않는다. 실제 LG 시스템·해지·가입·상담 접수는 연결되지 않았다. 고객 이해도·상담 준비시간·유지율 개선은 실측 성과로 제시하지 않는다.
