# 정수기 계약 상담 — CX 문제 정의

## 대표 페르소나

이서연(가명), 35세 경영지원 사무직. 배우자·자녀와 거주하며 가정의 정수기 구독 계약·요금을 관리한다. 인물·나이·직업·가족은 가상 설정이다.

| 층 | 설정 |
|---|---|
| Static | 가정 정수기 구독·요금 담당, 스마트폰·노트북 이용 |
| Dynamic | 현재 정수기를 유지할지 새 모델로 재구독할지 고민. 기존 계약 종료일·정산과 새 구독 비용을 함께 확인하고 싶음 |
| Meta | 불필요한 추가 부담을 피하고 근거를 이해한 뒤 자율적으로 선택하고 싶음 |

## 사용자·상황·문제

정수기 구독 고객은 유지·교체·해지를 고민하는 상황에서, 자신의 계약기간·종료 비용과 새 구독 조건을 함께 확인하기 어려워 다음 행동을 판단하는 데 불편을 겪는다.

사용 불편·이사·비용 부담·새 기능 필요는 계약 판단의 촉발 상황이다. 사용 불편 자체는 LG 공식 AI Chat으로 안내하고, 우리 Agent는 그 뒤 필요한 계약 판단을 지원한다.

## 데이터 근거

KCA 2025 피해구제 1,462건 중 계약823건, 계약 안 해지·위약금503건. 정수기대여 상담 누적6,902건은 전체 주제 규모이며 모두 계약 상담이 아니다. 표준답변의 관리/AS 불편과 해지 동시 언급 질문은 계약 판단이 발생하는 상황의 근거다. 피해구제 자료는 LG 전체 고객의 구성·유지/재구독 수요를 입증하지 않는다.

## As-Is / To-Be

| As-Is | To-Be |
|---|---|
| 공개 안내와 내 계약의 기간·정산, 신규 상품 조건을 따로 확인 | 필요한 계약 항목 조회 → 모델 후보 선택 → 기존 종료 비용 포함 동일 기간 비교 → 미확인 조건 구분 → 고객용 상담 준비서 |

## 4D 욕구

- 정신적: 계약·비용 불확실성 줄이기.
- 물리적: 흩어진 조건 확인과 상담 준비 수고 줄이기.
- 문화적: 계약 용어를 쉬운 말로 이해하기.
- 사회적: 가족·상담사에게 선택 근거 설명하기.

욕구와 고객 효과는 사용자 검증 대상이다. 실제 해지·가입·상담 접수는 수행하지 않는다. 명확한 해지 요청에 불필요한 유지·재구독 설득을 붙이지 않는다.
