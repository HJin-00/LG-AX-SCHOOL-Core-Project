# 보완 분석 실행·검산

- 노트북 코드 5개 셀을 프로젝트 .venv에서 실제 실행하고 결과·표·그래프를 저장했습니다.
- 표준답변 전체 1,332행, 정수기대여 43행, 공백 제거 고유 질문 31개를 assert로 검산했습니다.
- 내용 코딩은 질문 번호별 수작업 매핑이며 raw 구분을 유지했습니다. 43개 번호 전부가 분류에 포함됨을 확인했습니다.
- 해지 언급 31행/21고유질문, 관리·AS·품질 촉발+해지 동시 언급 13행/9고유질문입니다. 고객 발생 빈도로 해석하지 않습니다.
- KCA 전체 피해구제 1,462건, 계약 하위 합계 823건, 연령 확인 1,441건 합계를 검산했습니다.
- 두 그래프를 생성한 후 실제 이미지를 확인했습니다. 서로 다른 분모는 별도 패널로 표시했습니다.
- KCA 신규 HTML 다운로드는 TLS 인증서 오류로 실패를 기록했습니다. 인증서 검증을 끄지 않고 웹 도구에서 확인한 공식 내용 기록을 사용했습니다. LG 3개 원문은 다운로드 성공입니다.
- 현행 개별 법적 결론이나 LG 전체 고객 이탈률·혜택 선호·유지율 향상은 분석 결과로 주장하지 않습니다.
- 노트북 실행에는 Pandas·pypdf·Matplotlib·nbformat·nbclient·ipykernel이 사용됐고, 실제 서비스/API 서버와 외부 LLM은 실행하지 않았습니다.

RAG·응답 회귀 검증: 공식 혜택 기간·조건·포인트 비차감·비용 카드 병행 출처 보존 테스트, React 빌드 통과. 새 20개 사용자 시나리오는 미실시이며 위 개발 검증과 구분합니다.
