# 2019년 정수기 피해예방주의보 웹 확인 기록

출처: https://www.kca.go.kr/home/sub.do?menukey=4005&mode=view&no=1002835270&page=3
게시일: 2019-08-21. 확인일: 2026-10-08.

직접 HTML 수집은 인증서 검증 오류로 실패했습니다. 인증서 검증을 끄지 않았으며, 웹 도구가 제공한 공식 본문에서 아래 내용을 확인했습니다. 이 파일은 원문 HTML이 아닌 확인 기록입니다.

2018.01~2019.06 피해구제 951건에서 채권추심 177건을 제외한 774건이 분석 대상입니다. 계약 221건, 제품 품질 217건, 관리서비스 152건, 설치 102건, 렌탈료 75건입니다. 본문에 열거되지 않은 차액 7건은 분석 검산용이며 원문 분류명을 임의로 붙이지 않았습니다.

본문은 관리서비스 불만 또는 계약 이행 문제로 중도해지를 요구하는 과정에서 위약금 외 비용 분쟁이 발생할 수 있음을 설명합니다. 이는 불편과 계약 판단의 연결 근거입니다. 현재 LG 고객의 발생률·이탈률이나 2025년 통계와 동일한 분류의 시계열이 아닙니다.
