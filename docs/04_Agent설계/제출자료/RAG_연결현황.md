# 공개 지식 연결 현황

승인 검색 문서 58개와 기존 검수 청크 7개를 공용 검색에 연결했다. 승인 문서에서 현재 121개 청크를 구성하며 원문 무결성, 모델 적용 범위, 용도 제한을 확인한다. 새 문서의 출처는 최종 응답에서도 로컬 검증 메타데이터로 재구성한다.

개인 계약 PDF는 별도 조회 도구에서 필요한 항목만 추출하고 공용 RAG에 넣지 않는다. 공개 자료를 개인 비용 계산 규칙으로 자동 전환하지 않는다. 한국소비자원 상담/법령 저장본은 일반 참고용이며 현행 법령·개별 계약의 법적 적용을 확정하지 않는다.

수신 자료의 승인 기록을 대조한 것이며 58개 전체를 이번 작업에서 독립적으로 의미 검수하거나 현재 웹사이트를 다시 확인했다는 뜻은 아니다. 모델별 사용하기·문제해결 미승인 범위는 추가 검토가 필요하다. n8n 원문 수집·AI 검수 초안과 LangChain 고객 상담을 분리한다.

공개 청크 128개는 LangChain OpenAIEmbeddings(text-embedding-3-large)로 변환해 로컬 Chroma에 저장한다. 표준답변 질문을 포함한 검색용 구간 440개에서 의미 검색과 키워드 순위를 결합한다. 적용 모델·승인 상태·목적 제한을 검색 전후로 확인하고 원문 전체와 출처를 반환한다. 개인 계약·대화는 인덱싱하지 않으며 금액은 전용 계산 도구로 처리한다. 문서나 임베딩 모델이 바뀌면 재구축하고, 인덱스/임베딩 장애 시 키워드 검색을 사용한다.

유사도가 낮거나 후보 점수가 비슷하면 공개 후보의 실제 상황을 제한적으로 재검토한다. 원문 질문·참고 설명과 고객 질문을 비교하며, 후보에 없는 ID·개인 계약·비용 판단은 생성하지 않는다. 검토 결과를 일반 키워드가 다시 덮지 않도록 했고 재검토 장애는 원래 벡터 순위로 복구한다.
