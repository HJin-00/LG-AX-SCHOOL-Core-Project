# 정수기 계약 상담 AI — 기능 명세서

LG AX SCHOOL 4팀

## 해결하는 문제

정수기 구독 고객은 유지·교체·해지를 고민하는 상황에서, 자신의 계약기간·종료 비용과 새 구독 조건을 함께 확인하기 어려워 다음 행동을 판단하는 데 불편을 겪는다.

## 범위

계약 상담과 새 모델 재구독 비교는 유지한다. 사용 조작·고장 진단·자가조치·관리 방문 일정 상담은 직접 수행하지 않는다. 제품의 핵심 기능은 재구독 모델 선택 자료로 사용한다. 신규 구매 추천은 공식 제품 페이지로 연결한다.

## 도구 선택

Agent 노출 도구는 11개. 현재 질문과 명세를 보고 단일 LLM이 선택한다. 단어별 코드가 업무 도구를 강제 호출하지 않는다. 서버는 권한·입력·날짜·금액·파일 소유권을 검증한다. 같은 요청의 동일 도구·인자는 중복 실행을 재사용하고 개인 권한은 다시 확인한다.

## 계약정보 관리

- 공개 문서는 공용 RAG. 개인 계약은 권한 도구로 분리, 공용 RAG에 넣지 않는다.
- 가상 계약 PDF에서 필요한 모델·기간·요금·정산 규칙만 추출. 미납·납부 내역은 별도 가상 청구 데이터.
- MySQL은 로그인·동의 범위·만료·준비서 소유권 관리에 사용한다. 세션별 원본 계약 PDF 사본을 만들지 않는다.
- 로그인과 본인확인 시연·조회 동의를 구분. 채팅의 ‘동의합니다’는 권한 등록 아님.
- 비용에는 계약기간·비용 범위, 기간만이면 기간 범위 동의. 권한값은 서버가 주입하며 LLM·답변에 전달하지 않는다.
- 같은 탭 새로고침은 유효한 연결을 서버 재검증 후 복원. 만료·철회·로그아웃은 폐기.
- 준비서는 요청에 따라 생성·저장하며 소유권과 파일을 검증해 다운로드. 상담사에게 자동 전송하지 않는다.

## 계산 경계

새 모델 재구독 = 기존 계약 정산 + 전환일까지 추가 비용 + 새 구독료 + 확인된 초기비·관리비. 미확인 금액은 0원으로 대체하지 않는다. 확인일 가격과 미래 개인 가입 견적을 구분한다. 양수 할인반환금은 추가 부담이다. 종료일 당일/다음 날은 계약 규칙을 따른다. 관리 미이행·반복 하자는 일반 개인 사정 계산으로 책임·위약금 면제를 확정하지 않는다.

## 다른 모델 비교의 입력·선택

모델 미정이면 LLM이 기능·설치·관리 선호를 질문하며 React는 missing_fields=renewal_preferences 입력 화면을 표시한다. 후보 도구의 required_features, installation_type, care_mode, exclude_owned_model로 조건을 조회한다. 보유 모델 식별자는 서버에서 주입한다. 고객이 offer_id/새 모델을 선택하기 전 비교·준비서를 자동 실행하지 않는다. 자유 질문은 카테고리와 무관하게 현재 요청으로 판단한다.
