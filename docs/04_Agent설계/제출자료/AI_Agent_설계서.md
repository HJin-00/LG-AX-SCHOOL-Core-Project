# AI Agent 설계서

LG AX SCHOOL 4팀

## 1. Agent 개요

| 항목 | 내용 |
|---|---|
| 이름 | 정수기 계약 상담 AI |
| 사용자 | 현재 정수기를 유지할지, 다른 모델로 교체할지, 해지할지 고민하는 구독 고객 |
| 대표 사용자 | 이서연(35세·가명). 가정의 정수기 계약과 월요금을 관리한다. |
| 해결할 문제 | 내 계약의 기간·종료 비용과 새 구독 조건을 함께 이해하기 어려워 다음 행동을 판단하기 어렵다. |
| 목적 | 계약 조건과 선택별 부담을 확인해 고객이 유지·교체·해지 중 다음 행동을 결정하도록 돕는다. |

## 2. 수행 범위

| 지원하는 일 | 지원하지 않는 일 |
|---|---|
| 동의한 고객의 계약기간·요금·정산 조건 조회 | 타인 계약 조회, 권한 우회, 개인 계약의 공용 RAG 저장 |
| 오늘 또는 지정일의 예상 해지 비용 계산 | 실제 해지·가입·결제·자동이체 취소 |
| 고객이 고른 새 상품과 현재 유지 비용을 같은 기간으로 비교 | 미확인 요금·추가 비용을 임의로 계산하거나 0원 처리 |
| 교체 이유에 맞는 계약 설명·후보 비교·공식 지원 안내 | 해지 의사를 교체 요청으로 바꾸거나 제품 변경을 강요 |
| 요청한 상담 내용을 PDF로 정리하고 다운로드 제공 | 상담사 자동 전송·접수, 분쟁 책임·위약금 면제 확정 |

### 상담 흐름

계약 질문 → 필요한 조회·계산 → 결과 설명 → 고객이 고른 다음 행동. 해지 결정은 비용 확인으로, 교체 고민은 이유별 도움과 새 모델 선택으로 이어진다.

현재 검증에는 가상 고객 계약과 공식 공개 자료를 사용한다. 사용방법·고장 문의와 실제 계약 처리는 공식 상담 채널로 연결한다.

## 3. Agent 실행 구조

React → Node.js → FastAPI → LangChain 단일 Agent → RAG / FastMCP → 결과 검증 → 답변·PDF

LLM은 질문과 대화 맥락을 보고 필요한 도구를 선택한다. 서버는 조회 권한, 고객이 입력한 날짜·모델, 실행 결과와 파일 접근 권한을 확인한다.

| 유형 | 도구 | 입력과 결과 |
|---|---|---|
| 조회 | lookup_contract_document | 권한 범위·연결 고객 → 계약 모델·기간·요금·정산 조건 |
| 조회 | search_contract_knowledge | 질문·모델·목적 → 검증된 공개 근거와 출처 |
| 조회 | lookup_subscription_offers | 희망 기능·형태·관리·요금 조건 → 신규 구독 후보 |
| 조회 | lookup_product_features | 지정 모델·관심 기능 → 핵심 사양·가격·혜택 조건 |
| 조회 | get_official_channel | 상담 목적 → 공식 AI Chat·제품·계약 상담 링크 |
| 계산 | assess_contract_document_costs | 계약 권한·검토일 → 항목별 예상 정산 |
| 계산 | compare_contract_options | 계약 권한·두 날짜 → 정산·추가 요금·부담 차이 |
| 계산 | compare_retention_renewal | 선택 상품·전환일·기간·카드 → 유지/재구독 부담 |
| 판단 | suggest_contract_timing | 계약 권한·기준일 → 고객이 고를 시점 후보 |
| 생성 | create_contract_document_brief | 검증된 계약·정산 조건 → 상담 준비서 PDF |
| 생성 | create_renewal_brief | 선택 상품·동일 비교 조건 → 비교 상담 준비서 PDF |

### 근거와 개인 계약 관리

공개 문서는 Chroma 벡터 검색과 키워드 검색으로 찾는다. 유사한 후보가 겹치면 질문·상황을 다시 비교한다. 개인 계약 PDF는 공개 RAG와 분리하고 동의한 항목만 조회한다. MySQL은 계정·로그인·동의·준비서 접근 권한을 관리한다.

검색 자료: LG 구독·상품·혜택 안내, 한국소비자원 표준답변·피해예방 안내, 소비자분쟁해결기준 저장본.

### 주요 지침

현재 질문과 최신 선택을 우선한다. 도구 실행 없이 완료했다고 답하지 않는다. 공개 근거와 개인 계산을 구분하고, 가격·할인·면제를 추측하지 않는다.

### N10 | 두 날짜의 해지 부담 비교

질문: “2026-10-31과 2026-11-01 해지 예상비용을 내 계약 기준으로 비교해줘.”

| 단계 | 확인 내용 |
|---|---|
| 최초 판정 | 실패. 날짜별 정산 도구를 두 번 실행했지만 두 날짜 사이의 이용요금 비교가 빠졌다. |
