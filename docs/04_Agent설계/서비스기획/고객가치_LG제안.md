# 정수기 계약 상담 AI Agent 설계서

## 사용자와 목적

대표 페르소나 이서연(35세·가명)은 가정의 정수기 구독 계약을 관리한다. 유지·새 모델 재구독·해지를 검토할 때 자신의 계약기간과 정산 조건, 새 계약 부담을 이해하고 다음 행동을 결정한다. 연령·직업·가족 설정은 실제 고객 대표성이 입증된 정보가 아니다.

**CX 문제:** 정수기 구독 고객은 유지·교체·해지를 고민하는 상황에서, 자신의 계약기간·종료 비용과 새 구독 조건을 함께 확인하기 어려워 다음 행동을 판단하는 데 불편을 겪는다.

## 핵심 흐름

고객 질문 → 단일 LLM의 상황 판단 → 필요한 공개 계약·상품 근거 검색 / 동의한 개인 계약 조회 → 정산 또는 같은 기간 유지·재구독 계산 → 결과 검증 → 이해하기 쉬운 비용·조건·다음 행동 → 요청 시 상담 준비서.

날짜가 미정이면 계약 기준 후보를 확인한다. 새 모델은 기존 후보 목록에서 기능·관리·월요금을 보고 선택한다. 선택한 모델로 기존 해지 정산을 포함해 비교하며, 교체·유지·해지 중 특정 선택을 강요하지 않는다.

## 범위와 연결

| 직접 지원 | 공식 서비스로 연결 |
|---|---|
| 계약기간·요금·정산, 날짜별 부담, 새 모델 재구독 비교, 계약 근거, 상담 준비서 | 사용방법·오류·관리 일정 → LG AI Chat. 신규 구매 → LG 제품 페이지. 실제 해지·계약 변경·분쟁 확정 → 공식 상담 |

제품 주요 기능·가격 정보는 재구독 비교 자료로 유지한다. 사용 조작과 고장 진단은 수행하지 않는다. 개인 계약·청구는 가상 데이터, LG 고객정보·PASS·실제 신청·결제 연동은 미구현이다.

## 구조

React → Node.js(동일 출처 API·쿠키 중계) → FastAPI(세션·권한·입력/출력 검증) → LangChain 단일 LLM → RAG / FastMCP → 검증된 카드·준비서.

OpenAI/Anthropic은 환경 설정으로 선택한다. 모델에게 권한값을 전달하지 않는다. 개인 계약 PDF는 공용 RAG와 분리한다. 로그인·동의는 핵심 계산을 보호하는 기반 기능이며 발표의 주된 가치로 제시하지 않는다.

## 도구

11개 도구의 호출 조건·입력·결과·제한은 [기능 명세서](기능명세_도구호출.md)를 따른다. 조회, 계산·판단, 파일 생성 실행을 포함한다. 서비스 범위 안 도구 중 실제 선택은 LLM이 수행하고, 서버는 부적절한 권한·인자·분쟁 확정만 차단한다.

## RAG의 역할

계약기간·정산·분쟁의 일반 근거와 모델별 신규 구독 선택 조건을 검색한다. 승인 본문·해시·적용 모델을 검증한다. 공개 피해 통계는 개인 계약 요율이 아니다. 저장 가격은 확인일 스냅샷이며 미래 가입 견적을 보장하지 않는다. 사용법·오류 답변 대신 공식 AI Chat 연결을 제공한다.

## 평가

최종 범위의 사전 30사례: 정상18 / 애매6 / 위험6. 필요한 도구·정확한 근거·금액·권한·후속 행동을 모두 충족하면 해결, 일부 누락은 부분해결, 오답·허위 완료·권한 위반은 실패. 단위 테스트 건수를 고객 문제 해결률로 표현하지 않는다.

실제 결과와 재시험은 [평가 요약](../../05_평가/평가_개선_제출요약.md)을 참조한다. 과거 넓은 범위 평가와 합산하지 않는다. 이해도·정보 누락·상담 준비시간의 실제 고객 효과는 사용자 과제 평가가 필요하다.

## LG 제안

계약 조건 오해·상담에서 다시 확인할 정보의 누락을 줄이는 것을 목표로 한다. 기존 AI Chat과 사용 지원을 중복 구현하지 않고 계약 비교와 상담 준비에 집중한다. 유지율·재구독률·상담시간 효과는 미검증 가설이며 해지 방해를 제안 가치로 삼지 않는다.
